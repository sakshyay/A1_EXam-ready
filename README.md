# Ready, Set, Deutsch

A small, responsive A1 German learning check. Learners can reflect on their confidence, answer 12 questions across vocabulary, grammar and reading, then see a score by skill and tailored practice suggestions.

## Run it

No installation or build step is needed. Open `index.html` in a modern web browser.

## How the check works

- There are four questions in each of the three skills.
- Each correct answer adds one point to its skill score.
- A skill score of 3–4 is labelled **Looking strong**, 2 is **Building confidence**, and 0–1 is **Practise this next**.
- An overall score of 50% or higher displays a suggestion that the learner could move ahead with booking; below 50% suggests practising first. This is a product-design threshold for the prototype, not an official exam standard or pass prediction.
- The results recommend practice topics linked to missed questions.
- Learners may compare their self-reported strongest and practice areas with their quiz results.

This is a short learning check, not an official Goethe or ÖSD exam or a guarantee of passing. It does not assess writing or speaking.

## Files

- `index.html` contains the screen content.
- `styles.css` contains the visual design and mobile layout.
- `app.js` contains the questions, quiz flow, scoring and recommendations.
